# Prumathe home page / Portada de Prumathe

The pages that present Prumathe and link to the courses: what the project is, how a course works, the six courses with their entry points, and where the name comes from. One page in **English and Rioplatense Spanish** (switch at the top), light and dark appearance, no server, account, framework or external resource. Open [index.html](index.html) directly from the repository: the course links point to the sibling folders.

Las páginas que presentan Prumathe y enlazan a los cursos: qué es el proyecto, cómo funciona un curso, los seis cursos con sus puntos de entrada y de dónde viene el nombre. Una página en **inglés y español rioplatense** (selector arriba), apariencia clara y oscura, sin servidor, cuenta, framework ni recursos externos. Abrí [index.html](index.html) directamente desde el repositorio: los enlaces a los cursos apuntan a las carpetas vecinas.

## Files / Archivos

- `index.html`, `assets/site.js`, `assets/site.css`, `assets/theme.js`: the page, its bilingual text and its styles, with the courses' palette and type. / La página, su texto bilingüe y sus estilos, con la paleta y la tipografía de los cursos.
- `assets/favicon.svg`: the Prumathe mark, as in the courses. / La marca de Prumathe, como en los cursos.
- `404.html`, `_headers`: error page and headers for a static host; the CSP allows giscus, which shows the discussion of each lesson. / Página de error y cabeceras para un host estático; la CSP permite giscus, que muestra la discusión de cada lección.
- `scripts/build.mjs`: assembles the complete publishable site in `dist/` (ignored by Git). / Arma el sitio publicable completo en `dist/` (fuera de Git).

## Readable without JavaScript / Legible sin JavaScript

The published home page carries its whole text as static HTML, in both languages, for readers and tools that do not run JavaScript, such as the classifiers of web filters: `scripts/build.mjs` reads the data of `assets/site.js` and writes it inside `#app`, where `site.js` replaces it on load; `assets/theme.js` marks `<html data-js>` so it stays hidden while scripts run. The same build adds schema.org structured data (the site and its six courses), `robots.txt`, which allows every page, and `sitemap.xml`, with every page except the error pages and the lab kits. `index.html` declares the canonical address, a description of the six courses, keywords and Open Graph data. The build fails if a course folder has no card in `assets/site.js` or no link in the `<noscript>` of `index.html`.

La portada publicada lleva todo su texto como HTML estático, en los dos idiomas, para lectores y herramientas que no ejecutan JavaScript, como los clasificadores de los filtros web: `scripts/build.mjs` lee los datos de `assets/site.js` y los escribe dentro de `#app`, donde `site.js` los reemplaza al cargar; `assets/theme.js` marca `<html data-js>` para que queden ocultos mientras corren los scripts. El mismo build agrega datos estructurados de schema.org (el sitio y sus seis cursos), `robots.txt`, que permite todas las páginas, y `sitemap.xml`, con todas las páginas salvo las de error y las de los kits de laboratorio. `index.html` declara la dirección canónica, una descripción de los seis cursos, palabras clave y datos de Open Graph. El build falla si una carpeta de curso no tiene tarjeta en `assets/site.js` o enlace en el `<noscript>` de `index.html`.

## Publish / Publicar

`node site/scripts/build.mjs`, from the repository root, builds every course folder that has a `scripts/build.mjs` and writes `site/dist/`: this home page at the root and each course under its own name (`kafka-from-scratch/`, `docker-kubernetes-from-scratch/`, `github-from-scratch/`, `llm-rag-mcp-from-scratch/`, `entra-from-scratch/`, `cloudflare-from-scratch/`), with one `_headers` file for the whole site. On Cloudflare it is published as a Worker with static assets and no Worker code: the `wrangler.jsonc` at the repository root points to `site/dist` and serves `404.html` for unknown paths; in the dashboard, connect the repository with `node site/scripts/build.mjs` as build command and `npx wrangler deploy` as deploy command (Pages, the older product, would take the same build with `site/dist` as output directory). The site is published at https://prumathe.com, a domain associated with the Worker in the Cloudflare dashboard (not in `wrangler.jsonc`); it also answers at https://prumathe.andresdiegolanda.workers.dev. A new course only needs its folder beside this one.

`node site/scripts/build.mjs`, desde la raíz del repositorio, construye cada carpeta de curso que tenga `scripts/build.mjs` y escribe `site/dist/`: esta portada en la raíz y cada curso bajo su nombre (`kafka-from-scratch/`, `docker-kubernetes-from-scratch/`, `github-from-scratch/`, `llm-rag-mcp-from-scratch/`, `entra-from-scratch/`, `cloudflare-from-scratch/`), con un solo `_headers` para todo el sitio. En Cloudflare se publica como un Worker con archivos estáticos y sin código de Worker: el `wrangler.jsonc` de la raíz del repositorio apunta a `site/dist` y sirve `404.html` para las rutas desconocidas; en el panel, conectá el repositorio con `node site/scripts/build.mjs` como comando de build y `npx wrangler deploy` como comando de deploy (Pages, el producto anterior, tomaría el mismo build con `site/dist` como directorio de salida). El sitio está publicado en https://prumathe.com, un dominio asociado al Worker en el panel de Cloudflare (no en `wrangler.jsonc`); también responde en https://prumathe.andresdiegolanda.workers.dev. Un curso nuevo solo necesita su carpeta al lado de esta.

The course links carry the chosen language (`?lang=en` or `?lang=es`); each course keeps its own appearance and progress. The text of the cards (lesson and lab counts, requirements) is maintained by hand in `assets/site.js` when a course changes.

Los enlaces a los cursos llevan el idioma elegido (`?lang=en` o `?lang=es`); cada curso conserva su propia apariencia y su avance. El texto de las tarjetas (cantidad de lecciones y pasos, requisitos) se mantiene a mano en `assets/site.js` cuando un curso cambia.
