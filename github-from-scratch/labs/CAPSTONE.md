# Un cambio defendible / A defensible change

La entrega final de la lección 19 reúne el problema de horarios, propuesta, evidencia, decisión de integración y nota de entrega. Se puede hacer en GitHub o como caso de estudio identificado. La segunda opción demuestra razonamiento, no ejecución del servicio.

The lesson 19 handoff gathers the hours problem, proposal, evidence, integration decision and delivery note. Complete it on GitHub or as a labeled case study. The second route demonstrates reasoning, not service execution.

| Criterio / Criterion | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Estados / States | Confunde copias / Confuses copies | Identifica algunas / Identifies some | Distingue archivos, index, ramas y remotos / Distinguishes files, index, branches and remotes |
| Problema / Problem | Solo tarea vaga / Vague task | Resultado parcial / Partial outcome | Criterios observables / Observable criteria |
| Integración / Integration | Solo nombra botón / Names a button | Describe contenido / Describes content | Justifica contenido y ascendencia / Justifies content and ancestry |
| Evidencia / Evidence | Confunde modelo y ejecución / Confuses model and execution | Aporta una señal / Provides a signal | Relaciona cada afirmación con evidencia y límites / Links each claim to evidence and limits |
| Recuperación / Recovery | Propone forzar sin entender / Forces without understanding | Reconoce el error / Recognizes the mistake | Explica corrección compartida y trabajo sin registrar / Explains shared correction and unrecorded work |

Objetivo: al menos 8 de 10, sin cero en estados ni evidencia. No se puntúa recordar comandos, cantidad de clics ni velocidad. Si falta algo, volvé a la lección correspondiente y revisá la entrega. Esta rúbrica es una guía de autoevaluación, no una certificación.

Target: at least 8 of 10, with no zero in states or evidence. Command recall, click count and speed earn no points. Revisit the relevant lesson and revise the handoff when needed. This rubric is a self-assessment guide, not a certification.

Preguntas para defender la entrega / Questions for explaining the handoff:

1. ¿Qué cambió en main y qué no cambió en otra copia? / What changed on main and what stayed unchanged in another copy?
2. ¿Cómo detectaste el taller anterior a la apertura? / How did you detect the workshop before opening time?
3. ¿Qué demuestra el control automático y qué no? / What does the automated check prove and not prove?
4. ¿Qué historia deja tu estrategia de integración? / What history does your integration strategy leave?
5. ¿Cómo corregirías un horario publicado equivocado? / How would you correct a mistaken published schedule?
